

Controles
- W A S D = mover
- ESC = pausa
- R = reiniciar
- ESPACE = empezar

Objetivo
- Recolectar 50 cajas para ganar.

Elementos
- Camión (jugador)
- Caja amarilla (+1 punto)
- Combustible rosado (+25%)
- Boost morado (más velocidad)
- Objeto marrón (menos velocidad)
- Obstáculos negros

Condiciones de victoria
- Llegar a 50 puntos

Condiciones de derrota
- Chocar
- Quedarse sin combustible
